# Mariella

Ein Web-Projekt (HTML / CSS / JavaScript).

## Struktur

```
Mariella/
├── index.html      Einstiegsseite
├── css/style.css   Styles
├── js/main.js      Skripte
└── assets/         Bilder, Fonts, etc.
```

## Lokal ansehen

`index.html` im Browser öffnen — oder mit einem kleinen Server:

```powershell
python -m http.server 8000
```

Dann http://localhost:8000 aufrufen.
